# Command Reference

**STATUS: NOT YET IMPLEMENTED.** Webster currently defines no shipped commands, CLI syntax or executable names.

A future CLI, if approved, must use explicit verbs/options, safe argument parsing, no implicit elevation, bounded output, stable exit codes, redaction and documented confirmation for destructive operations. It must not accept arbitrary shell strings as management IPC. Proposed command families for design only: `webster status`, `webster diagnostics`, and `webster management`; these are examples, not available commands. Exact grammar and compatibility policy require an API proposal.
