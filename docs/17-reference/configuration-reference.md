# Configuration Reference

**STATUS: PROPOSED.** No Webster configuration keys or files have been implemented or frozen.

Future configuration entries must document key, type/schema version, scope (user/machine/policy), default, allowed values, privacy class, mutability, restart impact, precedence, migration and error behavior. Secrets must not appear in plaintext config or command-line arguments. Unknown fields are rejected or safely ignored according to the versioned schema; never reinterpret unknown security-sensitive values. See [configuration system](../06-system/configuration-system.md) and [installation configuration](../15-installation/configuration.md).
