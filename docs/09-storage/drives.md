# Drives

**STATUS: PROPOSED.** A drive view distinguishes physical devices, removable media, mapped/network resources and logical volumes; a drive letter is not a physical identity.

Show device/volume association, type, capacity, state, filesystem and observation time. Account for removable-media arrival/removal, offline devices and network mapping. Changes to a selected drive require re-resolution immediately before action. Health indicators are sourced and qualified; do not infer disk failure from one signal. Windows controls device drivers and I/O.
