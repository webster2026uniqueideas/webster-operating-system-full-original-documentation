# System Testing

**STATUS: PROPOSED.** End-to-end testing validates install, update, launch, desktop, management workflows, logoff, repair and uninstall on clean supported Windows environments.

Test low privilege, UAC denial, managed policy restrictions, unavailable APIs, sleep/resume, multi-monitor/DPI, RDP, limited connectivity, crash/restart and recovery. Verify Windows boot/logon remain unaffected if Webster fails. Destructive paths use disposable virtual disks/VMs and verified snapshots. Acceptance requires no unapproved host-state changes and truthful UI outcomes.
