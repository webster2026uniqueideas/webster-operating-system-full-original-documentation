# Notifications

**STATUS: PROPOSED.** Webster notifications communicate actionable, time-sensitive Webster state without becoming an alternate security prompt.

Notifications identify source, summary, urgency, timestamp and available action; group duplicates; allow dismissal and user-controlled categories; honor quiet/focus settings where supported; and expose equivalent accessible announcements. Sensitive account, network and administrative details are not displayed on a locked or shared screen unless policy permits. Notification actions re-check authorization and state when invoked. The Windows notification platform may be used as a **DEPENDENCY**; delivery and persistence are subject to OS policy. Never use a toast to request credentials or silently approve elevation.
