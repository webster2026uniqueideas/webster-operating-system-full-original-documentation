# Milestones

**STATUS: PROPOSED.** Milestones are evidence gates, not calendar commitments.

1. Scope and Windows support decision accepted; requirement IDs assigned.
2. Threat model, component trust boundaries and API versioning reviewed.
3. Native foundation builds reproducibly and passes unit/security baseline tests.
4. Desktop prototype meets accessibility, coexistence and failure-isolation criteria.
5. Read-only Computer Management inventory validated under standard-user context.
6. First privileged action has end-to-end authorization, confirmation, audit and rollback/recovery tests.
7. Release/update/uninstall pipeline proves signatures, compatibility and recovery.
8. Independent-OS research receives explicit approval or is formally deferred.

Owners, entry/exit criteria, dates and release commitments remain unassigned; record those once project governance exists.
