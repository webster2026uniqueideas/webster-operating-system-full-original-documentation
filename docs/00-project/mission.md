# Mission

**STATUS: PROPOSED.** Webster's mission is to design and incrementally build a dependable desktop and system-management platform, beginning as a native Windows-integrated environment.

The project will:
- deliver useful user-session experiences before attempting kernel work;
- use supported platform APIs and explicit ownership boundaries;
- make administrative changes consent-based, auditable and recoverable;
- build C++ components with modern resource safety and testable contracts;
- publish versioned requirements, APIs, limitations and compatibility policy;
- treat independent boot, kernel, drivers and filesystem work as a distinct future research program.

No listed capability is claimed as implemented. See [roadmap](../16-roadmap/development-phases.md).
