# Installation

**STATUS: PROPOSED.** Webster installation will be a signed, auditable Windows package; installer technology is unselected.

Installer requirements: verify package authenticity before execution; show publisher and scope; install protected machine binaries separately from user-writable data; request elevation only when selected features require it; configure optional startup/service items transparently; detect conflicts and OS capability; preserve user data; support repair/upgrade/uninstall; and leave host boot/security policy intact. No driver, firewall rule or persistent service is installed without explicit documented purpose/consent. Record installed component versions and support clean rollback.
