# System Requirements

**STATUS: PROPOSED.** No installable Webster package exists; minimum requirements are not yet validated.

Initial target is supported x64 Windows desktop versions to be selected before implementation, with ordinary-user launch and optional elevation only for specific administration. Exact Windows edition/build, CPU, memory, storage, graphics, .NET/runtime or other framework prerequisites, network needs and accessibility support are **RESEARCH / DEPENDENCY** decisions. Installation must detect unsupported systems and missing APIs rather than silently continue. Enterprise policy, antivirus, SmartScreen, UAC, virtualization and restricted profiles can affect operation. Publish a tested support matrix with each release.
